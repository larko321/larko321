# ROT13 Encoder/Decoder

A simple web-based tool to encode and decode text using the **ROT13 cipher**.  

ROT13 is a simple letter substitution cipher that replaces a letter with the 13th letter after it in the alphabet. This tool allows users to quickly encrypt or decrypt messages online.

## Features
- Encode text using ROT13
- Decode ROT13-encrypted text
- Easy-to-use web interface
- Works directly in the browser, no installation required

## How to Use
1. Enter your text into the input box.
2. Click **Encode** to encrypt or **Decode** to decrypt.
3. The result will appear immediately below.

## Technologies Used
- HTML
- CSS
- JavaScript

## Example
- Input: `Hello World`
- Output: `Uryyb Jbeyq`
